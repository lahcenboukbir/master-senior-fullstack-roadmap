# Learning Resources — Easy, Free, Beginner-Friendly
### Where to actually learn each part of the roadmap, without drowning

> **The rules this list follows**
> 1. **Free only.** Everything here costs nothing (some need a free account).
> 2. **Easy first.** Visual, example-driven, short. The hard stuff is in a separate "🔓 Later" line so it can't discourage you.
> 3. **Max 2–3 picks per topic.** More choices means more procrastination. Pick the first one, start, and only switch if it truly doesn't click.
> 4. **Tier-aware.** 🎯 Master sections get full coverage, 👀 Know-only sections get one quick overview, ⏸️ Skip sections get nothing yet (see the shelf at the bottom). Tiers come from [Priority_Map.md](Priority_Map.md).
> 5. **Official docs and tutorials beat random blog posts** when they're written for beginners. Where they're not, a video channel is listed instead.
>
> **Legend:** 🎬 watch · 📖 read · 🛠️ do (interactive / hands-on) · 🔓 later, when you're ready · ⏱️ rough time
>
> **Honesty note on links:** the ones marked ✅ were confirmed to exist by a web search on 2026-11-24. The rest are long-established resources written from knowledge, and I could not re-check each one. Links point to a site or channel home, not deep pages, so they rarely break. If one is dead, search the resource's name. YouTube channel names are given as plain names for the same reason: search them on YouTube.
>
> **Companion files:** [How_To_Learn_This_Roadmap.md](How_To_Learn_This_Roadmap.md) (the study method), [Exercises_And_Drills.md](Exercises_And_Drills.md) (practice), [Projects_And_Practice.md](Projects_And_Practice.md) (projects), [Progress_Tracker.md](Progress_Tracker.md).

# Part 0 — Foundation Reset (all 🎯 Master)

### 0.1 Linux as Daily Driver · 0.2 Terminal Mastery
- 🛠️ [Linux Journey](https://linuxjourney.com/) — start with "Grasshopper". ⏱️ 5–8h
- 🎬 / 📖 [MIT Missing Semester](https://missing.csail.mit.edu/) ✅ — the shell, Vim, tmux, scripting. Watch lecture 1 and 2 only at first. ⏱️ 2h
- 🔓 *The Linux Command Line* by William Shotts (free PDF at linuxcommand.org) — read after Linux Journey.

### 0.4 Chrome DevTools
- 📖 [Chrome DevTools docs](https://developer.chrome.com/docs/devtools) — the official "Overview" and "Network" pages. ⏱️ 2h
- 🎬 Search YouTube: *"Chrome DevTools crash course"* (Traversy Media or freeCodeCamp).

### 0.5 Git Internals & Discipline
- 🛠️ [Learn Git Branching](https://learngitbranching.js.org/) — a visual game that makes branches and rebase click. ⏱️ 3h
- 📖 [Oh Shit, Git!?!](https://ohshitgit.com/) — fixes for common mistakes. Keep it open.
- 📖 [Pro Git book](https://git-scm.com/book) — free; read chapters 1–3 only. Chapter 10 ("Git Internals") is the 🔓 later part.

### 0.6 HTML Semantics · 0.7 CSS Fundamentals
- 🛠️ [The Odin Project — Foundations](https://www.theodinproject.com/) — HTML & CSS lessons with projects.
- 🎬 **Kevin Powell** — start with his "CSS for beginners" playlist.
- 🛠️ [Flexbox Froggy](https://flexboxfroggy.com/) and [CSS Grid Garden](https://cssgridgarden.com/) — 1h each, fun.
- 📖 [web.dev Learn HTML / Learn CSS](https://web.dev/learn) — short, well-made courses by the Chrome team.

### 0.8 How HTTP Really Works
- 📖 [MDN — An overview of HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview) — then "HTTP request methods" and "HTTP status codes". ⏱️ 2h
- 📖 [Cloudflare Learning Center](https://www.cloudflare.com/learning/) — "What is HTTP?", "What is DNS?", "What is TLS?" in plain English.
- 🛠️ Use the DevTools Network tab while browsing and watch real requests.

### 0.9 Environment & Habits
- No resource needed. The habits are in [How_To_Learn_This_Roadmap.md](How_To_Learn_This_Roadmap.md).

# Part I — Core Engineering Foundations

## Phase 1 — Computer Science Fundamentals

### 1.1 CPU · 1.2 Memory Hierarchy · 1.3 Operating Systems (🎯)
- 🎬 **Crash Course Computer Science** (YouTube, 40 short episodes) — the best friendly intro to how computers work. Watch episodes 1–10 (CPU, memory) and the OS episodes. ⏱️ ~3h
- 🎬 [CS50 — Introduction to Computer Science](https://cs50.harvard.edu/x/) — free Harvard course; lectures 0 and 4 (memory) are especially helpful. ⏱️ optional, long
- 🔓 *Operating Systems: Three Easy Pieces* (free at ostep.org) — friendly for a textbook, but still a textbook. Later.
- 🔓 Ben Eater's "8-bit computer" videos — amazing, but only if you're curious about hardware.

### 1.4 Networking Deep Dive (👀)
- 📖 [Cloudflare Learning Center](https://www.cloudflare.com/learning/) — TCP, DNS, CDN explained simply.
- 🎬 Search: *"How does the internet work"* (Computerphile or Crash Course).
- 🔓 *Computer Networking: A Top-Down Approach* — later.

### 1.5 How the Browser Works (🎯)
- 📖 [Inside look at modern web browser](https://developer.chrome.com/blog/inside-browser-part1) — a 4-part illustrated series by the Chrome team. ⏱️ 1.5h
- 📖 [MDN — How browsers work](https://developer.mozilla.org/en-US/docs/Web/Performance/How_browsers_work)

### 1.6 Compilers, Interpreters & the JVM (🎯)
- 🎬 Fireship — "Java in 100 seconds" for a first look.
- 📖 [Baeldung — JVM architecture](https://www.baeldung.com/jvm-vs-jre-vs-jdk) and the neighbouring JVM articles.
- 🔓 [Crafting Interpreters](https://craftinginterpreters.com/) (free online book) — beautiful, but a big project. Later.

## Phase 2 — Data Structures & Algorithms

> **Do the practice in Java** (see Phase 5B.1). Visualize first, code second.

### 2.1 Complexity (Big-O)
- 🎬 **freeCodeCamp** — "Big O Notation" beginner video (search it). ⏱️ 1h
- 📖 [Big-O Cheat Sheet](https://www.bigocheatsheet.com/) — keep as reference.

### 2.2–2.8 Arrays, Linked Lists, Stacks/Queues, Hash Maps, Trees, Heaps, Graphs
- 🎬 **freeCodeCamp — "Data Structures Easy to Advanced Course"** by William Fiset. Use it as a reference, and watch only the structures you're on. Skip the advanced chapters. ⏱️ chapter by chapter
- 🛠️ [VisuAlgo](https://visualgo.net/) and [USFCA Data Structure Visualizations](https://www.cs.usfca.edu/~galles/visualization/Algorithms.html) — watch each structure operate step by step. This is the fastest way to *get* them.
- 🛠️ [NeetCode roadmap](https://neetcode.io/roadmap) — a free, ordered list of problems by topic with video explanations. Start with the "Easy" tier only.
- 🛠️ [Exercism — Java track](https://exercism.org/tracks/java) — small exercises with optional human mentoring.
- 🔓 *Algorithms* by Jeff Erickson (free PDF) — university-level. Later.

### 2.11 Sorting · 2.12 Searching & Shortest Paths
- 🛠️ [VisuAlgo](https://visualgo.net/) — Sorting page. Watch each algorithm run.
- 🎬 Search: *"sorting algorithms visualized"* ("15 Sorting Algorithms in 6 Minutes" is a fun classic).
- 🎬 **Abdul Bari** (YouTube) — slow, clear algorithm lectures; use for binary search and Dijkstra.

### 2.13 Dynamic Programming
- 🎬 **freeCodeCamp — "Dynamic Programming – Learn to Solve Algorithmic Problems & Coding Challenges"**. ⏱️ 5h, in chunks
- 🛠️ NeetCode's "1-D DP" section — only after recursion feels comfortable.
- ⚠️ DP is the topic that scares people most. If it doesn't click after a few tries, **move on and come back in a month**. That's normal.

### 2.15 Problem-Solving Patterns
- 🛠️ NeetCode's pattern-grouped lists (same site as above).

## Phase 3 — Software Design & Clean Code

### 3.1 Clean Code · 3.2 SOLID · 3.5 Refactoring (🎯)
- 🎬 **CodeAesthetic** — "Why you shouldn't nest your code", "Abstraction", "Stop writing classes" and the like. Short and visual. ⏱️ 10–15 min each
- 📖 [Refactoring Guru — Refactoring](https://refactoring.guru/refactoring) — each "smell" explained with before/after code.
- 📖 [Refactoring Guru](https://refactoring.guru/) — search the site for "SOLID" for plain-language examples.

### 3.3 Design Patterns (🎯) · 3.4 Architecture Patterns (🎯)
- 📖 [Refactoring Guru — Design Patterns](https://refactoring.guru/design-patterns) — the friendliest pattern catalog, with Java examples. Read ~1 pattern a day.
- 🎬 **Christopher Okhravi — Design Patterns playlist** (YouTube) — excellent, a bit slower and deeper. Use for the patterns you find confusing.
- 📖 Martin Fowler's site: [martinfowler.com](https://martinfowler.com/) — search "Presentation Domain Data Layering" for layered architecture. 🔓 Clean/Hexagonal architecture pieces can wait.

### Project Lifecycle & Planning
- 📖 [Atlassian Agile Coach](https://www.atlassian.com/agile) — user stories, backlogs, sprints, in plain English.
- 📖 [Mermaid docs](https://mermaid.js.org/) and the [Mermaid Live Editor](https://mermaid.live/) — practice diagrams as text.

# 😮‍💨 Feeling Stuck or Discouraged? Read This

1. **Switch format, not topic.** If an article loses you, watch a 10-minute video. If a video loses you, find an interactive version (VisuAlgo, SQLBolt, Learn Git Branching).
2. **Go one level down in difficulty.** Stuck on Spring Security? Do the Spring Boot REST guide again. Stuck on DP? Do recursion/Fibonacci again. This isn't failing, it's how learning works.
3. **Fireship's "in 100 seconds" videos** give you the shape of a topic in two minutes, so a longer resource feels less foreign.
4. **Use the 🔓 Later items as a map, not a to-do list.** They exist so you know the next step, not so you feel behind.
5. **Don't collect resources.** Pick one per topic, finish a piece of it, and build something small with it. Watching three tutorials on the same topic is procrastination in disguise.
6. **Ask Claude to explain it differently.** "Explain 8.2 Indexing like I'm new, with a library analogy" works. Then go back to the resource.
